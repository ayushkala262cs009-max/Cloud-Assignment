# Cloud-Assignment Evaluation Utilities

This project implements a calibrated baseline protocol, calibration gate, matched-control ablation support, and a forward-only GARNN temporal branch for trajectory-imputation evaluation.

## Run the calibrated protocol

```bash
python /home/runner/work/Cloud-Assignment/Cloud-Assignment/calibrated_protocol.py \
  --data-root /home/runner/work/Cloud-Assignment/Cloud-Assignment/data_corrupted \
  --checkpoint /home/runner/work/Cloud-Assignment/Cloud-Assignment/lstm_baseline.pt \
  --output-dir /home/runner/work/Cloud-Assignment/Cloud-Assignment/reports/calibrated_protocol \
  --test-seeds 17 18 19 20
```

## Fixed protocol settings

- Input window: `30 x 7` at `10 Hz`
- Label horizon: `50 x 2`
- Penetration rates: `10%, 20%, 30%`
- Metrics: Euclidean ADE/FDE (metres), masked-cell reconstruction MAE
- Lane-change criterion minimum: `n >= 200`
